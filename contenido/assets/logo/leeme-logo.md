# Logo — FD_

**Concepto:** las iniciales FD + un cursor de terminal. El guion bajo celeste es "el builder que está escribiendo": simple, memorable y tuyo. Nada de esto es SVG dibujado a mano — es tipografía real compuesta por código (script incluido).

**Tipografía:** Archivo Black / Archivo (Omnibus-Type — fundición de Buenos Aires 🇦🇷, licencia SIL OFL, incluida en `../fuentes/`). Detalle lindo: el logo usa una tipografía argentina.

**Colores:**
| Nombre | Hex | Uso |
|---|---|---|
| Ink | `#0E1116` | letras sobre fondo claro |
| Blanco | `#F5F7FA` | letras sobre fondo oscuro |
| Celeste | `#74ACDF` | el cursor `_` (celeste bandera), acento de marca |

**Archivos:**
- `fd-monograma-ink.png` / `fd-monograma-blanco.png` — monograma para nav, footer, avatar.
- `wordmark-ink.png` / `wordmark-blanco.png` — "FELIPE DOVAL_" para hero o footer.
- `favicon-512/192/32.png`, `apple-touch-icon-180.png` — listos para usar.
- `generar_logo.py` — el script que produce todo; cambiás un hex y regenerás.

**Para Opus:** usar los PNG tal cual (alta resolución, fondo transparente). El celeste `#74ACDF` puede servir de punto de partida para el acento del design system, pero la paleta final la define el plan de diseño.

**¿Y si algún día quiero SVG?** Abrí Figma, escribí "FD_" con Archivo Black, mismo tracking y colores, y exportá — 5 minutos. Para la web, estos PNG sobran.
