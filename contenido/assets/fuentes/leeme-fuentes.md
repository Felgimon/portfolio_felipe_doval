# Tipografías

- `ArchivoBlack-Regular.ttf` — display pesada, la del logo.
- `Archivo-Variable.ttf` — variable (ejes wdth + wght), sirve de body/UI si el plan de diseño la adopta.
- `OFL.txt` — licencia SIL Open Font License: permite uso comercial y embeber en la web sin drama.

**Para Opus:** si el plan de diseño elige Archivo, cargala con `next/font/local` desde acá (mejor performance y consistencia logo↔sitio). Si elige otra tipografía, estas quedan solo para el logo.

Origen: repo oficial de Google Fonts (github.com/google/fonts), fundición Omnibus-Type (Buenos Aires).
